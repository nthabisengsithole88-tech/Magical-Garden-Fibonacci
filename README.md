A Scratch program that brings math to life! Users specify growth days to observe the Fibonacci sequence in action within a magical garden setting. Built to showcase core programming logic, loop control, and variable management.
# Magical Garden Fibonacci

An interactive Scratch project created as part of the **ALX Africa Data Science Program**. This program demonstrates core programming logic and computational thinking by simulating garden growth using the Fibonacci mathematical sequence.
---
## Project Overview

In this project, users are prompted to enter a target number of days to let the magical garden grow. Using loop conditions, temporary variables, and sequential addition, the program calculates and displays the exact number of flowers produced on each day according to the Fibonacci sequence ($1, 1, 2, 3, 5, 8, 13, \dots$).

## Skills & Concepts Demonstrated

* **Algorithmic Thinking:** Implementing the Fibonacci algorithm ($F_n = F_{n-1} + F_{n-2}$) visually.
* **Variable Management:** Manipulating dynamic variables (`day`, `target day`, `current flowers`, `next flowers`, `temp`).
* **Control Structures:** Utilizing `repeat until` loops and conditional logic.
* **User Interaction:** Gathering input via user prompts and outputting customized messages.
* **Problem Solving:** Translating abstract mathematical formulas into functional Scratch code.
